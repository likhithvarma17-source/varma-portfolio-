# Likhith Varma Kutchalapati – Portfolio (React + Vite)

## Run locally
Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

`npm run dev` starts Vite with `--host`. Open the Local URL on your computer, or the
Network URL on your phone (same Wi-Fi).

## Personalize
- Edit **`src/data.js`**: LinkedIn, GitHub, projects, text.
- Put your resume at **`public/resume.pdf`**.
- Colors and spacing live at the top of `src/styles.css`.

## Publish with GitHub Pages
```bash
git init
git add .
git commit -m "Add portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```
Then on GitHub: Settings > Pages > Source: **GitHub Actions**.
Your link: `https://YOUR-USERNAME.github.io/YOUR-REPO/`
